## 🧾 Project Summary

The **ORETA Shop Management System** replaces the company’s manual operations with a centralized, fully digital solution. Designed with usability and performance in mind, it supports daily operations such as inventory tracking, sales, purchasing, delivery, and employee management — all in real-time.

---

## 🚀 Key Functional Modules

| Module                | Description                                                                 |
|-----------------------|-----------------------------------------------------------------------------|
| 📦 **Inventory Management**   | Track raw materials & finished goods in real-time                             |
| 🧾 **Sales & Orders**          | Automated billing, secure payments, and stock updates                        |
| 🚚 **Delivery Management**     | Track deliveries, upload proof of delivery                                   |
| 🔗 **Supplier Management**     | Manage supplier profiles, stock orders, and order history                    |
| 👨‍💼 **Employee Management**   | Handle attendance, payroll, leaves, and training                              |
| 🛒 **Customer Management**     | Track customer orders, apply personalized discounts                          |
| 📄 **Documentation System**    | Store manuals, maintenance logs, and equipment documents                     |
| 💰 **Purchase Management**     | Manage budgets, purchase orders, and analytical reports                      |
